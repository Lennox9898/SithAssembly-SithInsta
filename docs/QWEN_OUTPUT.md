# Qwen Output Contract

This contract makes Qwen output useful to read without turning a generated interpretation into a case fact. The machine-readable source is `config/qwen_response_contract.json`.

## Display Order

```text
Evidence facts
- A readable statement with linked evidence IDs and source references.

Qwen model assessment - probabilistic interpretation, not a verified fact
Plain-language explanation generated by the model.
Confidence: 0.00 to 1.00
Basis: linked evidence IDs

Uncertainties
- Missing context, alternatives and limits.

Review questions
- Concrete questions for an analyst.
```

The first section contains only statements that can point to provided evidence IDs. The second section is deliberately visible as readable prose: it is Qwen's generated interpretation of the supplied context and its learned probability distribution, not an independently verified finding.

## Example

```json
{
  "evidence_facts": [
    {
      "statement": "The captured comment contains the domain example.org.",
      "evidence_ids": ["evidence:91"]
    }
  ],
  "model_assessment": {
    "label": "Qwen model assessment - probabilistic interpretation, not a verified fact",
    "readable_text": "Based on the supplied excerpts, the repeated domain may be relevant for further review. The available evidence alone does not establish coordination.",
    "confidence": 0.62,
    "basis_evidence_ids": ["evidence:91", "evidence:104"]
  },
  "uncertainties": [
    "No independent information about the domain owner is included.",
    "The sample size is limited."
  ],
  "review_questions": [
    "Are there additional captured observations that use the same domain?"
  ]
}
```

The UI should render `readable_text` below the linked facts, not hide it in a JSON inspector. The label, confidence and evidence links stay adjacent to the text so its status remains clear.
